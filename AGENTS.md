# AGENTS.md

## Purpose

Public Homebrew tap for installing Noam Siegel's agentic-coding tools.

## Scope

This repo owns formula packaging only. Product behavior, version constants, release tags, and changelogs live in upstream product repos.

## Formula inventory

- `Formula/agents-toc.rb`: generated by GoReleaser from `noamsiegel/agents-toc`; do not hand-edit except during emergency repair.
- `Formula/git-guardrails.rb`: manually maintained source-tarball formula.
- `Formula/agents-trace.rb`: manually maintained source-tarball formula.
- `Formula/git-wt.rb`: manually maintained source-tarball formula.

## Editing rules

- Keep formula structure boring and consistent: `desc`, `homepage`, `url`, `sha256`, `license`, `head`, `depends_on`, `install`, `caveats` if needed, `test`.
- Do not add aliases or previous formula names.
- Do not hand-edit GoReleaser-managed fields in `agents-toc.rb`; fix upstream release config instead.
- Keep README install commands aligned with formula file names.
- Update `RELEASING.md` when release mechanics change.
- Dogfood `agents-trace`: AI-authored PRs must run `agents-trace pr-attach` and carry exactly one `🤖 agents-trace:` marker; direct emergency pushes without a PR must run `agents-trace gist-create` or `agents-trace collect` for local audit evidence.

## Verification

For changed manual formulas, run targeted Homebrew checks from repo root:

```bash
brew audit --new --strict --online Formula/<formula>.rb
brew install --build-from-source Formula/<formula>.rb
brew test Formula/<formula>.rb
```

For documentation-only changes, run a dead-reference search for old formula names and inspect results before yielding.
